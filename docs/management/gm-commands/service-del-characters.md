# `.service del_characters`

- Security: Administrator (4)
- Console: yes
- Handler: `HandleServiceDeleteCharacters`

Syntax:

```text
.service del_characters <flags> [max_level] <max_level> <max_money> <max_items> <max_played_time> <logout_time>
```

Example:

```text
.service del_characters 1 1 1 1 1 1
```
