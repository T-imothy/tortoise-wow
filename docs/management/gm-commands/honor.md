# `.honor`

- Security: Administrator (4)
- Console: no
- Subcommands: `.honor show`, `.honor setrp`

Syntax:

```text
.honor <subcommand>
```

Example:

```text
.honor show
```

---

## `.honor show`

- Security: Developer (3)
- Console: no
- Handler: `HandleHonorShow`


---

## `.honor setrp`

- Security: Developer (3)
- Console: no
- Handler: `HandleHonorSetRPCommand`

Syntax:

```text
.honor setrp <on|off>
```

Example:

```text
.honor setrp on
```
