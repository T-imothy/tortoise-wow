# `.unit`

- Security: Developer (3)
- Console: no
- Subcommands: `.unit speedinfo`, `.unit statinfo`

Syntax:

```text
.unit <subcommand>
```

Example:

```text
.unit speedinfo
```

---

## `.unit speedinfo`

- Security: Developer (3)
- Console: no
- Handler: `HandleUnitSpeedInfoCommand`


---

## `.unit statinfo`

- Security: Developer (3)
- Console: no
- Handler: `HandleUnitStatInfoCommand`
